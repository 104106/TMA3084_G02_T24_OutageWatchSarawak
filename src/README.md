# Source Code

This folder contains the actual Flutter application for OutageWatch Sarawak.

**What belongs here:**
* Flutter project files (`lib/`, `test/`, etc.)
* `pubspec.yaml`
* Android/iOS build configurations

**Note to developers:** Our GitHub Actions CI/CD pipeline automatically runs `flutter analyze` and `flutter test` on this folder whenever a Pull Request is opened. Ensure your code passes locally before pushing!
