# TSPi Process Forms & Logs

This folder is for all Team Software Process (TSPi) tracking documents and meeting records. 

**What belongs here:**
* Meeting Minutes (Client and Team meetings)
* LOGAI (AI Usage Tracking)
* LOGD (Defect Log)
* LOGTEST (Test execution records)
* LOGT (Time tracking)
* WEEK (Weekly status reports)
* SCHEDULE / TASK forms
* PEER evaluation forms

**Note:** Please update these logs continuously throughout the sprint, not just the night before a deadline!
